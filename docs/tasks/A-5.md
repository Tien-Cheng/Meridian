### A-5: Animated Arc Layer for Supply Routes
- **Tier:** 2
- **Est. time:** 45 min
- **Depends on:** A-3
- **Blocks:** none
- **Files:** `app/investigation/[id]/components/InvestigationMap.tsx`
- **Output contract:**
  - Supply route arcs animate in with a progressive draw effect
  - Verified high-risk routes are solid red; unverified are dashed amber at 50% opacity
  - Arc width varies by `riskLevel` (critical = thickest)
  - Markers for high-risk/critical findings have a brief pulse animation on creation (2 sec, then static)
- **Acceptance criteria:**
  - At least one animated route arc is visible in demo
  - Verified vs unverified routes are visually distinguishable
  - Animations don't cause performance issues or jank
- **Gotchas:**
  - deck.gl `ArcLayer` does NOT natively support marching-ants or draw-in animation
  - Options: (a) animate `getWidth` with `requestAnimationFrame` and a time-based parameter, (b) use `PathLayer` with `getDashArray` for dashed lines, (c) CSS overlay for glow effects
  - Keep it simple — even a static arc with a glow class is better than a broken animation
  - If deck.gl animation proves too complex, fall back to Mapbox GL JS `addLayer` with `line-dasharray` animation
  - The design doc says "marching ants" for unverified — this is a `line-dasharray` animation in Mapbox
