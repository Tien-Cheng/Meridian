### A-3: Wire Map Tooltips and Auto-Fit
- **Tier:** 1
- **Est. time:** 40 min
- **Depends on:** S0-2
- **Blocks:** A-5, INT-2
- **Files:** `app/investigation/[id]/components/InvestigationMap.tsx`
- **Output contract:**
  - ScatterplotLayer shows tooltips on hover: listing title, seller name, price deviation %, risk level (with color coding: emerald=low, amber=medium, red=high/critical)
  - ArcLayer shows tooltips on hover: from-region → to-region, risk level, concern text. Data comes from `supplyRoutes` table.
  - Map auto-fits viewport to contain all markers when findings data first loads
  - Clicking a marker highlights the corresponding finding in the Evidence tab (callback to parent)
- **Acceptance criteria:**
  - Hovering a marker shows a dark-themed tooltip with title, seller, price, deviation %, risk level
  - Hovering a route arc shows source region, destination region, risk level, and concern text
  - Map viewport adjusts to fit all data points on initial load and when new findings arrive
  - No tooltip flicker or positioning bugs
- **Gotchas:**
  - deck.gl tooltips use the `getTooltip` prop on the `DeckGL` component, NOT on individual layers
  - For auto-fit, use `WebMercatorViewport.fitBounds()` — handle empty findings array gracefully (don't call fitBounds on zero points)
  - The existing map component already passes `layers` — add `getTooltip` as a sibling prop
  - Marker click → evidence highlight requires lifting state up or using a shared context/store
  - Tooltip content should use monospace font for price figures per the design doc style guide
  - Marker color is determined by `riskLevel` field (not `isSuspicious` boolean): emerald for `"low"`, amber for `"medium"`, red for `"high"` or `"critical"`. The findings query must return `riskLevel` and `riskScore`.
  - Tooltip should also show pharma-specific indicators when available: pharmacy credentials status, prescription required status.
