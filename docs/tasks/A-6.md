### A-6: Landing Page Demo Button
- **Tier:** 1
- **Est. time:** 20 min
- **Depends on:** A-2
- **Blocks:** none
- **Files:** `app/page.tsx`
- **Output contract:**
  - A "LOAD DEMO" button on the home page (below or alongside "New Investigation")
  - Clicking it calls the `seedDemo` mutation, then navigates to `/investigation/[id]`
  - The investigation page loads with all demo data pre-populated
- **Acceptance criteria:**
  - Button visible on home page with appropriate styling (amber outline, monospace label)
  - Click → seed → redirect completes in <2 seconds
  - Investigation page shows: markers on map, findings in evidence panel, case in case panel
- **Gotchas:**
  - Must handle auth — button should only work for signed-in users
  - Thread creation via agent component must happen before investigation creation
  - Use `useMutation` from Convex React to call seedDemo, then `router.push()` to redirect
  - Add loading state to button during seed operation
  - Consider adding a check to prevent duplicate demo investigations
