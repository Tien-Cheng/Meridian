### A-4: Polish RightPanel Tab Badges
- **Tier:** 1
- **Est. time:** 20 min
- **Depends on:** S0-2
- **Blocks:** none
- **Files:** `app/investigation/[id]/components/RightPanel.tsx`
- **Output contract:**
  - Tab switch has a subtle CSS transition (~150ms opacity/transform)
  - Evidence tab header shows count badge: `EVIDENCE (N)` where N = findings count
  - Case tab shows green dot/checkmark icon when a case file exists
  - Chat tab is the default active tab during investigation
  - Auto-switch to Case tab when investigation status becomes `"completed"`
- **Acceptance criteria:**
  - Tab transitions are visually smooth (no layout shift)
  - Evidence count updates reactively as new findings arrive
  - Case tab visually indicates when case is ready
- **Gotchas:**
  - Need `useQuery` calls in RightPanel to get counts — add lightweight queries for `findings.listByInvestigation` (just `.length`) and `cases.getByInvestigation` (existence check)
  - Auto-switch on completion requires watching the investigation `status` field
  - Keep tab state in component state, not URL — simpler for hackathon
