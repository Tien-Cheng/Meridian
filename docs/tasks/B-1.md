### B-1: Implement searchMarketplace Tool
- **Tier:** 1 (CRITICAL PATH — highest priority task in the entire hackathon)
- **Est. time:** 60 min
- **Depends on:** S0-1
- **Blocks:** B-2, B-3, B-5
- **Files:** `convex/tools/searchMarketplace.ts`
- **Output contract:** The tool's `execute` function:
  1. Calls `callTinyFish()` from `convex/lib/tinyfish.ts` with a search goal
  2. Processes SSE stream via `processTinyFishStream()` (already implemented)
  3. Returns structured JSON: array of `{ title, price, currency, sellerName, listingUrl, imageUrls?, shippingInfo?, pharmacyBadgeVisible?, prescriptionRequired?, batchNumber?, expiryDate?, sellerRating?, sellerAccountAge?, productDescriptionSnippet? }` matching `ListingExtractionSchema`
  4. Handles errors gracefully (returns error message string, doesn't crash)
- **Acceptance criteria:**
  - TinyFish call succeeds for at least one marketplace (test with Amazon.com or Lazada.sg)
  - Returns at least 1 parsed listing with title, price, sellerName, listingUrl
  - Error case returns a descriptive string, not an unhandled exception
- **Gotchas:**
  - **THIS IS THE HIGHEST-RISK TASK.** TinyFish is a browser automation agent — results depend entirely on how well the natural-language goal is engineered.
  - The TinyFish "goal" prompt must be very specific. Suggested:
    ```
    Go to {marketplaceUrl}. Search for "{searchQuery}". On the search results page,
    extract ALL visible product listings. For each listing, extract: product title,
    price as a number, currency symbol, seller or merchant name, and the full listing URL.
    Also note: whether any pharmacy or verification badge is visible on the listing or
    seller, whether a prescription is mentioned as required, any batch number or expiry
    date visible, and seller rating or account age if shown.
    Return the results as a JSON array of objects.
    ```
  - TinyFish may take 30-90 seconds per call — test early
  - The result from TinyFish comes as a `result` field in the COMPLETE event. Its shape is unpredictable — may be a JSON string, a JSON object, or plain text
  - **If TinyFish returns plain text or garbage JSON:** Use the `extractorAgent` (GPT-5.4-mini) as a normalization pass to parse the raw output into structured data
  - **FALLBACK (activate by 12:30 if TinyFish is unreliable):** Hardcode 5-6 mock Ozempic/semaglutide listings with pharma-specific fields populated. Use seller names from design doc: "HealthDirect_SG", "Health_Direct_Official", "PharmaDeals_US". This unblocks the entire pipeline.
  - The `callTinyFish` function in `convex/lib/tinyfish.ts` already handles SSE parsing and monitor updates — study it before implementing
  - `proxy_config: { enabled: true }` is important for marketplace access from TinyFish's servers
