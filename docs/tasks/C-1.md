### C-1: Implement clusterSellers Tool
- **Tier:** 1
- **Est. time:** 50 min
- **Depends on:** S0-1 (OpenAI key available)
- **Blocks:** C-2
- **Files:** `convex/tools/clusterSellers.ts`
- **Output contract:** The tool's `execute` function:
  1. Accepts `findingsJson` (serialized findings data) as input — the calling action (C-2) queries DB and passes data in
  2. Calls OpenAI GPT-5.4-mini via `generateObject` from `ai` SDK with `SellerClusteringSchema` from `shared/schemas.ts`
  3. Returns valid `SellerClustering` shape: `{ clusters: [{ clusterId, sellerNames, signals, confidenceScore, networkRiskLevel }] }`. The `signals` object includes `sharedShippingOrigin: boolean`.
- **Acceptance criteria:**
  - Makes OpenAI API call with structured output using the Zod schema
  - Returns valid `SellerClustering` shape with at least 1 cluster when given 2+ sellers
  - Handles edge case: 0 or 1 unique sellers → returns empty clusters array
- **Gotchas:**
  - **Architecture decision:** The `createTool` execute function receives `(_ctx, input)` where `_ctx` is the agent tool context, NOT a Convex action context. The tool CANNOT directly query the DB.
  - **Recommended approach:** Add `findingsJson: z.string()` to the input schema. The calling action (C-2) queries findings, serializes them, and passes the JSON string. The tool deserializes, calls GPT, and returns clusters.
  - **Alternative:** Implement the GPT call entirely in C-2 and make this tool a thin wrapper. This is simpler but less reusable.
  - The prompt to GPT-5.4-mini should include:
    ```
    Analyze these pharmaceutical marketplace listings and identify seller accounts that
    likely belong to the same operator distributing potentially counterfeit medications.
    Compare: seller name similarity, shared product images, similar listing descriptions,
    overlapping pharmaceutical product catalogs, shared shipping origin. Group related
    sellers into clusters. Assign a confidence score (0-1) and a network risk level
    (low/medium/high/critical) to each cluster.
    ```
  - Use `@ai-sdk/openai` and `generateObject()` with `schema: SellerClusteringSchema`
  - If OpenAI is slow or rate-limited, add a 30-second timeout
