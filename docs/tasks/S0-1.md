### S0-1: Lock Environment Variables
- **Tier:** Setup (prerequisite)
- **Est. time:** 10 min
- **Depends on:** none
- **Blocks:** S0-2, B-1, C-1, C-3
- **Owner:** All builders (Builder B leads)
- **Files:** `.env.local`, Convex dashboard env vars
- **Output contract:** All env vars set in both local `.env.local` and Convex deployment:
  - `TINYFISH_API_KEY` — Convex env var
  - `OPENAI_API_KEY` — Convex env var
  - `NEXT_PUBLIC_MAPBOX_TOKEN` — `.env.local` (client-side)
  - `NEXT_PUBLIC_CONVEX_URL` — `.env.local` (auto-generated by `npx convex dev`)
- **Acceptance criteria:**
  - `pnpm run dev` starts without missing-env errors
  - Convex dashboard shows `TINYFISH_API_KEY` and `OPENAI_API_KEY` set
  - Quick `curl` test to TinyFish endpoint returns 200 (not 401)
- **Gotchas:**
  - Convex env vars are set via `npx convex env set KEY value` or the dashboard, NOT `.env.local`
  - `.env.local` is only for Next.js client-side vars (`NEXT_PUBLIC_*`)
  - TinyFish API key may have rate limits — confirm quota with hackathon organizers
  - OpenAI key may be a shared hackathon key — check model access for `gpt-5.4` and `gpt-5.4-mini`
