### B-3: Implement inspectListing Tool
- **Tier:** 1
- **Est. time:** 45 min
- **Depends on:** B-1 (establishes TinyFish call pattern)
- **Blocks:** B-4, B-6
- **Files:** `convex/tools/inspectListing.ts`
- **Output contract:** The tool's `execute` function:
  1. Calls `callTinyFish()` with a goal to open a specific listing URL
  2. Extracts: full seller name, seller storefront URL, product image URLs, shipping info, product description, pharmacy badge/verification status, whether prescription is mentioned as required, any visible batch number or expiry date, seller rating and account age
  3. Returns structured JSON with seller details and pharma-specific fields
- **Acceptance criteria:**
  - TinyFish opens a specific listing URL (not a search page)
  - Extracts seller name and at least one additional detail (storefront URL or shipping info)
  - Returns structured data, not raw page text
- **Gotchas:**
  - The goal must be specific: "Open this product listing page. Extract: full product title, current price, seller name, seller storefront URL if available, all product image URLs, shipping/delivery information, whether any pharmacy license or verification badge is displayed on the listing or seller profile, whether a prescription is required to purchase, any batch number or expiry date printed on product images or in the description, and the seller's rating and account age. Return as JSON."
  - Different marketplaces have different page layouts — the goal must be generic enough to work across Amazon, Lazada, Shopee
  - Include "scroll down to see seller information" in the goal — seller details are often below the fold
  - Seller storefront URLs on Amazon follow the pattern `/storefront/SELLER_ID` — TinyFish should extract this
  - If TinyFish can't find a storefront URL, return `null` — don't fail the whole extraction
  - This tool is called per-listing, so it could be called 3-5 times in sequence — watch TinyFish rate limits
