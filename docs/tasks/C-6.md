### C-6: Pre-baked Agent Messages for Panic Demo
- **Tier:** Panic fallback
- **Est. time:** 30 min
- **Depends on:** none (can start immediately)
- **Blocks:** none
- **Files:** New file `convex/lib/demoMessages.ts`, possibly `convex/functions/chat.ts`
- **Output contract:**
  1. A set of 6-8 realistic agent messages simulating investigation narration
  2. A mutation or function to insert these messages into a thread with correct timestamps
  3. Messages cover all investigation phases:
     - "Starting investigation across 3 marketplaces..."
     - "Found 12 listings on Amazon.de, 8 on Amazon.fr..."
     - "Flagging 4 suspicious listings based on price deviation..."
     - "Investigating seller 'BeautyDeals_EU' on Amazon.de..."
     - "CONFIRMED: This listing ships to France. Verified via cart check."
     - "Found matching seller patterns: 78% confidence same operator."
     - "Investigation complete. 2 verified violations identified."
- **Acceptance criteria:**
  - Messages read naturally as investigation narration
  - Messages can be inserted into an agent thread
  - When rendered in the ChatPanel, they appear as agent messages (not user messages)
- **Gotchas:**
  - Check `@convex-dev/agent` API for inserting historical messages — may need to use internal component mutations
  - Messages should have incrementing timestamps (~30 seconds apart) to simulate real-time investigation
  - The `role` must be `"assistant"` for agent messages
  - If the agent component doesn't support direct message insertion, consider using the `saveMessage` function with a role override
  - This is the nuclear fallback — only used if both live TinyFish AND mock data paths fail
  - Messages should reference the same data as A-1's demo data (same seller names, same regions, same numbers)
