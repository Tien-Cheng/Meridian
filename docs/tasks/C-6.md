### C-6: Pre-baked Agent Messages for Panic Demo
- **Tier:** Panic fallback
- **Est. time:** 30 min
- **Depends on:** none (can start immediately)
- **Blocks:** none
- **Files:** New file `convex/lib/demoMessages.ts`, possibly `convex/functions/chat.ts`
- **Output contract:**
  1. A set of 6-8 realistic agent messages simulating pharmaceutical investigation narration
  2. A mutation or function to insert these messages into a thread with correct timestamps
  3. Messages cover all investigation phases:
     - "Starting pharmaceutical safety investigation across 3 marketplaces: Amazon US, Lazada Singapore, Shopee Singapore..."
     - "Found 8 listings on Amazon, 14 on Lazada, 9 on Shopee. Running risk signal assessment..."
     - "6 listings flagged as high-risk based on pricing anomalies and missing pharmacy credentials."
     - "WARNING: Seller 'HealthDirect_SG' on Lazada has Ozempic at 90% below legitimate market price. No pharmacy credentials visible. Account is 3 months old."
     - "CRITICAL FINDING: This injectable prescription medication listing has NO prescription verification in checkout. Shipping origin: Shenzhen, China."
     - "Found matching seller patterns: 'HealthDirect_SG' on Lazada and 'Health_Direct_Official' on Shopee — 82% confidence same operator."
     - "Investigation complete. 6 high-risk listings identified, 1 seller network uncovered. Evidence pack ready for regulatory review."
- **Acceptance criteria:**
  - Messages read naturally as pharmaceutical investigation narration
  - Messages can be inserted into an agent thread
  - When rendered in the ChatPanel, they appear as agent messages (not user messages)
- **Gotchas:**
  - Check `@convex-dev/agent` API for inserting historical messages — may need to use internal component mutations
  - Messages should have incrementing timestamps (~30 seconds apart) to simulate real-time investigation
  - The `role` must be `"assistant"` for agent messages
  - If the agent component doesn't support direct message insertion, consider using the `saveMessage` function with a role override
  - This is the nuclear fallback — only used if both live TinyFish AND mock data paths fail
  - Messages should reference the same data as A-1's demo data: Ozempic scenario, seller names "HealthDirect_SG" and "Health_Direct_Official", regions Amazon US / Lazada SG / Shopee SG, matching risk scores and finding counts.
