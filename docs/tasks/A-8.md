  2. Components themed to match investigation console aesthetic:
     - `border-radius: 0` on all elements
     - `font-mono` for data readouts (prices, IDs, timestamps)

     - `<Conversation>` + `<ConversationContent>` for auto-scrolling container

  - Chat panel renders agent messages with proper markdown (headers, bold, code blocks)
  - Tool calls show as collapsible sections with status badges (pending/running/completed/error)
  - User input works: Enter sends, Shift+Enter for newline
  - Auto-scroll to bottom on new messages
  - Streaming text renders correctly (incomplete markdown handled by streamdown)
  - Visual style matches design doc: dark, sharp edges, monospace data, no rounded corners
- **Gotchas:**
  - AI Elements installs like shadcn — editable source files, not a node_modules import. Install command is likely `npx ai-elements@latest add conversation message prompt-input tool` (verify with latest docs)
  - Must add `@source "../node_modules/streamdown/dist/*.js"` to `globals.css` for Tailwind to scan streamdown's classes
  - Convex Agent's `UIMessage` extends AI SDK's `UIMessage` — the data should flow directly into AI Elements components WITHOUT an adapter
  - The existing ChatPanel.tsx has a working implementation — study its data hooks before rewriting the rendering
  - AI Elements may have dependencies on `@ai-sdk/react` — install if needed
  - Theme customization is done by editing the installed source files directly (like shadcn), not via CSS overrides
  - If AI Elements installation fails or is too complex, FALLBACK: keep the existing ChatPanel rendering and just add markdown support via `react-markdown`
