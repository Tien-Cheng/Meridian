### B-6: Implement crawlStorefront Tool
- **Tier:** 2
- **Est. time:** 40 min
- **Depends on:** B-3
- **Blocks:** none
- **Files:** `convex/tools/crawlStorefront.ts`
- **Output contract:** The tool's `execute` function:
  1. Calls `callTinyFish()` with a goal to visit a seller's storefront page
  2. Extracts all listings from that seller matching pharmaceutical products / the target drug name
  3. Returns array of `{ title, price, currency, listingUrl }`
  4. Also extracts seller metadata: display name, rating, account age if visible
- **Acceptance criteria:**
  - TinyFish navigates to seller storefront URL
  - Extracts at least listing titles and prices from the storefront
  - Filters results to pharmaceutical products (especially the target drug and related medications)
- **Gotchas:**
  - Not all marketplaces have public seller storefronts
  - Amazon storefronts are at URLs like `https://www.amazon.com/storefront/SELLER_ID` or `https://www.amazon.com/shops/SELLER_ID`
  - Lazada and Shopee may use different storefront URL patterns
  - If the storefront URL is not available (wasn't extracted by inspectListing), return gracefully with "storefront not accessible"
  - The goal should mention the drug name to filter: "Find all listings from this seller related to pharmaceutical products, especially '{drugName}' and similar medications"
  - This data feeds into seller clustering (C-1) — more listings per seller = better cluster confidence. Finding additional pharmaceutical listings (e.g., other prescription drugs) from the same seller strengthens the counterfeit network signal.
  - Extracted listings can be added as additional findings to strengthen the evidence
