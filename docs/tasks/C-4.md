### C-4: Implement generateCase Action
- **Tier:** 1
- **Est. time:** 30 min
- **Depends on:** C-3
- **Blocks:** INT-1
- **Files:** `convex/functions/investigations.ts` (fill in `generateCase` handler at ~line 123)
- **Output contract:** The `generateCase` internalAction handler:
  1. Queries findings, supply routes (from `supplyRoutes` table), and dossiers for the investigation
  2. Serializes evidence data and calls GPT-5.4 via C-3's tool (or directly)
  3. Computes count fields from actual DB data (NOT GPT's estimates):
     - `totalListingsFound` = total findings count
     - `suspiciousListings` = findings where `riskLevel` is `"medium"`, `"high"`, or `"critical"`
     - `highRiskListings` = findings where `riskLevel` is `"high"` or `"critical"`
     - `sellerNetworksIdentified` = dossier count
  4. Creates `cases` entry via `ctx.runMutation(internal.functions.cases.create, ...)` with all schema fields including `publicHealthRiskAssessment`
  5. Updates investigation status to `"completed"`
- **Acceptance criteria:**
  - Case file created in DB matching the full `cases` schema in `convex/schema.ts`
  - `findingSummaries` reference real finding `_id` values (as strings) and include `riskScore`, `riskLevel`, `topRiskSignals`
  - `sellerDossierSummaries` include `networkRiskLevel`
  - `recommendedActions` include `targetEntity` for each action (e.g., "Singapore HSA", "Lazada Trust & Safety", "FDA")
  - Count fields are computed from DB data, not GPT-generated
  - Title follows pattern: `"Pharmaceutical Counterfeit Investigation: {drugName} — {date}"`
  - `generatedAt` is `Date.now()`
  - Case includes `publicHealthRiskAssessment` addressing patient safety implications
- **Gotchas:**
  - Must map GPT output finding IDs (strings) back to Convex IDs for the `findingSummaries` array
  - The `cases.create` mutation needs `threadId` — pass it through from the workflow args
  - If GPT fails or times out, create a minimal case file with just the counts and a generic summary
  - The investigation status update to `"completed"` should happen AFTER the case is successfully created
  - The workflow in `convex/workflows/investigate.ts` calls this as the final step — when it completes, the frontend auto-switches to the Case tab
