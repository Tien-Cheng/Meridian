### B-8: Launch Investigation Workflow from Chat
- **Tier:** 1
- **Est. time:** 30 min
- **Depends on:** B-7
- **Blocks:** INT-1
- **Files:** `convex/functions/chat.ts`, `convex/workflows/investigate.ts`, possibly `convex/functions/investigations.ts`
- **Output contract:** The chat-triggered investigation flow:
  1. Looks up the investigation record by `threadId` after the first user prompt is saved
  2. Starts `investigationWorkflow` exactly once when the investigation is still pending and parsed fields are available
  3. Preserves the existing assistant streaming/chat narration path while the workflow runs in parallel
  4. Leaves follow-up messages conversational only; they must not start a second workflow run
- **Acceptance criteria:**
  - The first investigation prompt sent from the chat panel moves the investigation off `"pending"` and into the workflow status transitions
  - Duplicate workflow launches do not happen on retries, refreshes, or subsequent user prompts
  - Follow-up chat prompts still save and stream normally after the workflow has started
  - The UI can trigger the full backend flow without any manual dashboard action
- **Gotchas:**
  - `convex/workflows/investigate.ts` already defines the workflow; this task is about invoking it from the chat path, not rebuilding the workflow logic
  - Add an idempotency guard before launch so repeated submits do not create duplicated findings/routes/cases
  - If B-7 produced a clarification-needed result, skip workflow launch and keep the thread in chat-only mode
  - Launch should use the persisted investigation record, not re-parse the prompt a second time
