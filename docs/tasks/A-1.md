### A-1: Hardcoded Demo Data Module
- **Tier:** Panic fallback
- **Est. time:** 30 min
- **Depends on:** S0-2
- **Blocks:** A-2, A-6
- **Files:** New file `convex/lib/demoData.ts`
- **Output contract:** Exports `getDemoFindings()`, `getDemoRoutes()`, `getDemoCase()`, `getDemoDossiers()` returning arrays matching the `findings`, `shippingRoutes`, `cases`, and `sellerDossiers` schema shapes. Covers the SK-II demo scenario across 3 regions (Germany, France, Singapore).
- **Acceptance criteria:**
  - Data matches Convex schema types exactly (validated against `convex/schema.ts`)
  - Includes mix of suspicious (4-5) and non-suspicious (3-4) findings across all 3 regions
  - Coordinates use values from `REGION_COORDINATES` in `convex/lib/constants.ts`
  - Price deviations span -5% to -40% for visual variety on the map
  - At least 1 shipping route from Germany to France (verified violation)
  - Case file includes 2-3 recommended actions
- **Gotchas:**
  - `investigationId` must be a placeholder — will be swapped at insert time in A-2
  - Finding `_id` values won't exist yet — `relatedListingIds` in dossiers must reference actual IDs created during seeding
  - Use realistic seller names: "BeautyDeals_EU", "EU_Beauty_Shop", "AsiaCosmetics_Direct"
  - Include `listingUrl` values pointing to real Amazon/Lazada product pages for demo credibility
