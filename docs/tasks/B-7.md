### B-7: Parse Investigation Prompt into Structured Request
- **Tier:** 1
- **Est. time:** 35 min
- **Depends on:** S0-2
- **Blocks:** B-8, INT-1
- **Files:** `convex/functions/chat.ts`, `convex/functions/investigations.ts`, `shared/schemas.ts`
- **Output contract:** The first substantive user prompt on a pending investigation:
  1. Is parsed into `InvestigationRequestSchema` using structured LLM extraction (`generateObject` or equivalent)
  2. Produces populated fields for `drugName`, `drugCategory`, `regions`, and `regulatoryContext`
  3. Persists the parsed investigation data onto the existing `investigations` record identified by `threadId`
  4. Derives `protectedMarket` for the current UI flow when it can be inferred; otherwise falls back to the first region name
  5. Returns a clarification path instead of launching if required fields are missing or ambiguous
- **Acceptance criteria:**
  - The demo prompt from C-5 parses into a valid Ozempic/semaglutide investigation with Amazon US, Lazada Singapore, and Shopee Singapore region objects
  - New investigations no longer remain blank after the first user prompt
  - Parsed `regions` include full schema fields (`name`, `marketplace`, `marketplaceUrl`, `legitimatePrice`, `currency`, `requiresPrescription`)
  - Follow-up chat messages do not overwrite the original parsed investigation request once launch has started
- **Gotchas:**
  - The current home page creates an empty investigation shell first; this task is responsible for backfilling real investigation fields before the workflow starts
  - `InvestigationRequestSchema` requires fully populated region objects, not just marketplace names
  - Keep first-message behavior separate from follow-up chat behavior; only parse when the investigation status is still `"pending"`
  - If the prompt is ambiguous, the assistant should ask a clarifying question in chat rather than launching a malformed workflow
  - Prefer strict schema validation and reject partial/guessed region objects that would break downstream workflow steps
