### B-4: Implement deepInvestigate Action
- **Tier:** 1
- **Est. time:** 45 min
- **Depends on:** B-3
- **Blocks:** INT-1
- **Files:** `convex/functions/investigations.ts` (fill in `deepInvestigate` handler at ~line 102)
- **Output contract:** The `deepInvestigate` internalAction handler:
  1. Queries all findings for this investigation where `isSuspicious === true`
  2. Sorts by price deviation (most suspicious first)
  3. For top 3 suspicious findings (Tier 1 limit), calls inspectListing logic to get enriched seller details
  4. Updates findings with enriched data (seller storefront URL, image URLs, etc.)
  5. Creates `shippingRoutes` entries:
     - **Tier 1:** Assume shipping when deviation > 20% (no live cart check)
     - **Tier 2:** Call verifyShipping tool for actual verification
  6. Route coordinates: `from` = finding's region coordinates, `to` = protected market coordinates
  7. Severity mapping: deviation > 30% = "critical", > 20% = "high", > 15% = "medium", else "low"
  8. Updates monitor status to "inspecting" during this phase
- **Acceptance criteria:**
  - Iterates over suspicious findings (at least top 3)
  - At least one finding gets enriched with seller details
  - At least one `shippingRoutes` entry created via `ctx.runMutation(internal.functions.routes.createRoute, ...)`
  - Investigation status updates to "investigating" at start
- **Gotchas:**
  - This is an `internalAction` — all DB reads via `ctx.runQuery()`, all DB writes via `ctx.runMutation()`
  - Protected market coordinates come from `getCoordinates(args.protectedMarket)` using `convex/lib/geocoding.ts`
  - The `routes.createRoute` mutation needs: `investigationId`, `findingId`, `fromRegion`, `fromLatitude`, `fromLongitude`, `toRegion`, `toLatitude`, `toLongitude`, `verified`, `verificationMethod`, `priceGap`, `severity`
  - For Tier 1, set `verified: false` and `verificationMethod: "price_deviation_heuristic"`
  - Limit to 3 listings to keep TinyFish call count manageable and demo fast
  - If any individual inspectListing call fails, catch the error, log it, and continue with the next listing
