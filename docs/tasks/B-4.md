### B-4: Implement deepInvestigate Action
- **Tier:** 1
- **Est. time:** 45 min
- **Depends on:** B-3
- **Blocks:** INT-1
- **Files:** `convex/functions/investigations.ts` (fill in `deepInvestigate` handler at ~line 102)
- **Output contract:** The `deepInvestigate` internalAction handler:
  1. Queries all findings for this investigation where `riskLevel` is `"high"` or `"critical"` (using `by_risk` index)
  2. Sorts by `riskScore` descending (highest risk first)
  3. For top 3 high-risk findings (Tier 1 limit), calls inspectListing logic to get enriched seller details
  4. Updates findings with enriched data (seller storefront URL, image URLs, pharmacy credentials, etc.)
  5. Creates `supplyRoutes` entries:
     - **Tier 1:** Create supply route when `riskLevel` is `"high"` or `"critical"`. Set `verified: false` and `verificationMethod: "risk_signal_heuristic"`.
     - **Tier 2:** Call verifyShipping tool for actual verification
  6. Route coordinates: `from` = `shippingOrigin` coordinates (or finding region if unknown), `to` = finding region coordinates
  7. Route `riskLevel` derived from the finding's `riskLevel`. Include `concern` field describing the regulatory issue (e.g., "Prescription medication sold without Rx verification, shipped from non-manufacturer region").
  8. Updates monitor status to "inspecting" during this phase
- **Acceptance criteria:**
  - Iterates over high-risk/critical findings (at least top 3)
  - At least one finding gets enriched with seller details and pharma-specific fields
  - At least one `supplyRoutes` entry created via `ctx.runMutation(internal.functions.routes.createRoute, ...)`
  - Investigation status updates to "investigating" at start
- **Gotchas:**
  - This is an `internalAction` — all DB reads via `ctx.runQuery()`, all DB writes via `ctx.runMutation()`
  - Coordinates come from `getCoordinates(region)` using `convex/lib/geocoding.ts`
  - The `routes.createRoute` mutation needs: `investigationId`, `findingId`, `fromRegion`, `fromLatitude`, `fromLongitude`, `toRegion`, `toLatitude`, `toLongitude`, `verified`, `verificationMethod`, `riskLevel`, `concern`
  - Limit to 3 listings to keep TinyFish call count manageable and demo fast
  - If any individual inspectListing call fails, catch the error, log it, and continue with the next listing
