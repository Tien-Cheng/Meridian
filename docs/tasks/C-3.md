  2. Calls OpenAI GPT-5.4 (full model) via `generateObject` with `CaseGenerationSchema` from `shared/schemas.ts`
  3. Returns a complete case file object: executive summary, finding summaries, seller dossier summaries, recommended actions

  - GPT-5.4 may take 10-20 seconds for structured output of this complexity

  - The `CaseGenerationSchema` is in `shared/schemas.ts` lines 35-64 — verify it matches the cases table schema
