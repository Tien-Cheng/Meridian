### B-5: Implement verifyShipping Tool
- **Tier:** 2
- **Est. time:** 45 min
- **Depends on:** B-1
- **Blocks:** none
- **Files:** `convex/tools/verifyShipping.ts`
- **Output contract:** The tool's `execute` function:
  1. Calls `callTinyFish()` with a goal to: open listing → add to cart → go to checkout → check shipping to protected market
  2. Returns `{ canShip: boolean, shippingCost?: string, evidence: string }`
  3. Updates the finding via `findings.updateShippingVerification` mutation
  4. If `canShip === true`, creates a `shippingRoutes` entry with `verified: true`
- **Acceptance criteria:**
  - TinyFish navigates through cart → checkout flow
  - Returns a boolean shipping determination with evidence string
  - Finding record updated with `shippingVerified: true` and `shipsToProtectedMarket` result
- **Gotchas:**
  - **SECOND-HIGHEST-RISK TASK.** Cart flows are complex and marketplace-specific
  - The TinyFish goal should be very explicit:
    ```
    On this product listing, click "Add to Cart". Then go to the cart or checkout page.
    Look for shipping/delivery options or address selection. Check if shipping to {protectedMarket}
    is available. Report: can_ship (true/false), shipping_cost if shown, estimated_delivery if shown.
    Do NOT complete any purchase or enter payment information. Return as JSON.
    ```
  - TinyFish may hit CAPTCHAs or anti-bot detection during checkout flow
  - Some marketplaces require account login for checkout — TinyFish may not be able to proceed
  - **Fallback:** If this tool fails, B-4's Tier 1 heuristic (assume shipping based on price deviation) remains the active path
  - `verificationMethod` should be `"cart_shipping_check"` when this tool succeeds
  - Route `verified: true` and `severity` recalculated based on actual confirmation
